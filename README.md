## 💭 About the Project

**Periods are natural. The silence surrounding them shouldn't be.**

Breaking the Silence is an interactive menstrual-health awareness initiative designed to challenge misconceptions, break social stigma, and encourage informed conversations about menstruation.

In a world where menstruation is still surrounded by myths, embarrassment, and misinformation, this project aims to create a space where knowledge replaces fear and conversations replace silence.

Because understanding menstruation shouldn't be optional. It should be normal.

## 🎯 Our Mission

- 🩸 **Educate:** Make menstrual health information accessible and understandable.
- 🌱 **Break Myths:** Challenge outdated beliefs with facts and awareness.
- 🤝 **Encourage Conversations:** Promote openness, empathy and understanding.
- 🌍 **Create Awareness:** Explore menstrual health, period poverty and global perspectives.
- 📊 **Understand Perspectives:** Use surveys and data to understand awareness and attitudes.

## 🌿 Why Does This Matter?

Menstruation is a biological process, not a social taboo.

Yet millions of people continue to experience misinformation, discrimination, and barriers to menstrual hygiene.

This project is a small contribution towards a bigger conversation — one built on science, dignity, equality and awareness.
